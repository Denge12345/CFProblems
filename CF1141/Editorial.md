#### [CF1141A](https://codeforces.com/contest/1141/problem/A)
**题意**：给你一个整数 $n$，每一次操作你可以将其乘以 $2$ 或乘以 $3$，求使其转化为 $m$ 的最小操作次数，如果无法变成 $m$ 输出 `-1`。

**数据范围**：$1 \leq n \leq m \leq 5 \times 10^8$。

**思路**：直接用 BFS 模拟，使用 map 记录到达当前数字的最小操作次数。

#### [CF1141C](https://codeforces.com/contest/1141/problem/C)
**题意**：给定一个长度为 $n - 1$ 的排列 $p$ 的差分数组 $q$（$q_i = p_{i + 1} - p_i$），求出原来的排列 $p$，如果不存在输出 `-1`。

**数据范围**：$2 \leq n \leq 2 \times 10^5$，$-n \leq q_i \leq n$。

**思路**：设 $p_1 = x$，根据差分数组 $q$，可以得到后面每一项都可以写成 $x$ 加上一段前缀和的形式，如 $p_1 = x, p_2 = x + q_1, p_3 = x + q_1 + q_2, \dots$。记 $pre_0 = 0, pre_i = q_1 + q_2 + \dots + q_i$，那么第 $i$ 项就是 $p_i = x + pre_{i - 1}$。

排列 $p$ 必须是一个 $1 \sim n$ 的排列，则必须满足序列中最大值与最小值的差（极差）恰好为 $n - 1$，而整体加 $x$ 不改变极差，所以极差完全由 $pre$ 数组决定。令 $mx = max(pre), mi = min(pre)$，若 $mx - mi \neq n - 1$，则输出 $-1$。

接着我们需要确定 $x$，为了方便起见，我们可以让 x + pre 是序列中的最小值，而排列中最小的数是 $1$，则 $x + mi = 1$，即 $x = 1 - mi$。此时最大值是 $x + mx = 1 - mi + mx = 1 + (n - 1) = n$，使得所有值都在 $1 \sim n$ 这个范围。

然后我们就可以继续根据 $x = 1 - mi$ 和前缀和向后推导出排列中的每一项了（$p_i = x + pre_{i - 1}$），别忘了还要判断序列中 $1 \sim n$ 是否都出现了一次，最后输出排列即可。

#### [CF1141D](https://codeforces.com/contest/1141/problem/D)
**题意**：给定两个长度为 $n$ 字符串 $l$，$r$，字符串内字符都是小写字母或者问号，你需要将两个字符串中相同的字符进行匹配，如果是问号则匹配哪个字符都行，比如 $(f, f)$，$(?, a)$，$(?, ?)$。求最大匹配数量并输出匹配方案。

**数据范围**：$1 \leq n \leq 150000$。

**思路**：直接模拟进行匹配即可。定义两个大小为 $26$ 的 vector，$posL$ 和 $posR$，类型为 `vector<int>`，分别记录两个字符串中的字符和字符存在于哪个下标，再定义两个 vector，$qL$ 和 $qR$，分别记录两个字符串中问号的下标。

先进行小写字母匹配，遍历 $26$ 个小写字母，如果存在于 $posL$ 和 $posR$，从两个数组中对应字母的数组尾部拿下标，然后进行尾删，直到两个数组其中有一个为空就停止。

然后进行 $l$ 串的问号匹配，遍历 $26$ 个小写字母，如果 $posR$ 当前字母的数组还有下标，则从其尾部拿下标，然后进行尾删除，直到 $qL$ 和 $posR$ 对应字母的数组其中有一个为空就停止。

接着进行 $r$ 串的问号匹配，遍历 $26$ 个小写字母，如果 $posL$ 当前字母的数组还有下标，则从其尾部拿下标，然后进行尾删除，直到 $qR$ 和 $posL$ 对应字母的数组其中有一个为空就停止。

最后进行两个串的问号匹配，从 $qL$ 和 $qR$ 的尾部拿下标，直到两个数组中有一个为空。

最后按要求输出方案即可。

#### [CF1141E](https://codeforces.com/contest/1141/problem/E)
**题意**：有一位超级英雄和一只怪兽进行战斗，给定一个长度为 $n$ 的数组 $d$ 表示一轮战斗，$d_i$ 表示怪兽每一轮第 $i$ 分钟的血量变化。怪兽的初始生命值为 $H$，求怪物在哪一分钟会死亡，如果怪物永远不会死亡，输出 `-1`。

**数据范围**：$1 \leq H \leq 10^{12}$，$1 \leq n \leq 2 \times 10^5$，$-10^6 \leq d \leq 10^6$。

**思路**：首先我们可以想到，如果一轮下来怪物血量的变化量为大于等于 $0$，那么怪物肯定永远不会死亡，输出 `-1`，否则怪物一定会死。

接下来，我们模拟第一轮的情况，并记录 $mx$ 为第一轮内怪物扣的血量的最大值，$sum$ 为第一轮怪物扣的血量。如果在过程中怪物就死亡了，直接输出下标即可。

由于数据量太大，所以我们要使用公式进行跨轮计算。由于一轮内的伤害不是均匀分布的，有些分钟扣血特别多，有些分钟反而回血。如果我们直接算能活多少整轮（$\frac{H}{sum}$），可能会错把怪物在一轮半中间的死亡当成完整活过一轮。因此，为了安全的跳过 $t$ 整轮，我们必须保证跳过这些轮后的剩余血量仍然能抗住下一轮最危险的时刻，即 $H - t \times sum > mx$，移项得，$t < \frac{H - mx}{sum}$，$t = \lfloor\frac{H - mx}{sum}\rfloor$。

接着我们让 $H$ 减少 $t \times sum$，如果 $H$ 还有剩余，我们就可以模拟最后一轮（$t + 1$ 轮）的情况，直到 $H \leq 0$，输出答案即可。

#### [CF1141F1/CF1141F2](https://codeforces.com/contest/1141/problem/F1)
**题意**：给定一个长度为 $n$ 的数组 $a$，我们需要找到尽可能多的不相交区间 $(l_1, r_1), (l_2, r_2), \dots, (l_k, r_k)$，使得 $a_{l_1} + \dots + a_{r_1} = a_{l_2} + \dots + a_{r_2} = \dots = a_{l_k} + \dots + a_{r_k}$，输出满足题意的区间总数和区间。

**数据范围**：F1 为 $1 \leq n \leq 50$，F2 为 $1 \leq n \leq 1500$，$-10^5 \leq a_i \leq 10^5$。

**思路**：我们可以先 $O(n^2)$ 的计算所有可能的子段和，以及子段和的左端点和右端点。

接着遍历每一种的子段和，将该子段和对应的所有区间按照右端点从小到大排序，然后贪心地选取尽可能多的不相交的区间。

选取时，定义 $lst$ 为上一个选择区间的右端点，初始为 $0$，接着依次遍历当前子段和的数组 $(l, r)$，如果 $l > lst$ 则说明这个区间可与之前区间不重叠，可以选择，将区间加入到当前方案，并更新 $lst = r$。

遍历结束后如果当前方案选择的区间数量大于之前的数量，则更新答案，最后根据题意输出即可。


#### [CF1141G](https://codeforces.com/contest/1141/problem/G)
**题意**：给定一颗有 $n$ 个节点的树，树的边是双向的，定义如果一个公司到一个节点有两条及以上的道路，那么这个节点是坏的，你需要找到一个最小公司数量 $r$，使得存在一种从 $1$ 到 $r$ 的道路分配方式，满足不好的城市数量不超过 $k$。最后输出道路的分配方式。 

**数据范围**：$2 \leq n \leq 2 \times 10^5$，$0 \leq k \leq n - 1$

**思路**：我们可以通过二分得到满足不好的城市数量不超过 $k$ 的最小公司数量 $r$。注意存边的时候我们需要规定边 $u, v$，满足 $u$ 节点是小编号节点（或者 $v$ 节点是小编号节点），这是为了方便我们后续存答案。 

在二分的 `check()` 函数中，定义 $res$ 为不好的城市的数量，每次二分 $r$，如果在当前情况下，节点 $i$ 的度大于 $r$，就说明这个城市是不好的，因为无论怎样分配该节点的边，都不能满足每个公司都只有一条道路到达这个节点。当 $res$ 满足 $res \geq k$ 时，我们缩小 $r$ 的范围，搜索更小的 $r$，否则扩大 $r$ 的范围。

当求出 $r$ 后，我们可以使用 DFS 给每一条边进行染色，构造答案。

定义 `dfs(x, fa, r, fc)` 表示来到当前节点 $x$，父节点是 $fa$，公司数量是 $r$，上一条边的颜色为 $fc$。先定义 $color = 1$，然后遍历当前节点 $x$ 的一条边，如果是父节点则跳过，如果 $color = fc$，则让 $color$ 自增 $1$，如果 $color > r$，则让 $color$ 回到 $1$。然后我们给边 $u, v$ 进行染色，将答案记录到 `map<pair<int, int>, int> col` 中，然后向深层遍历，`dfs(y, x, r, color)`。注意当遍历当前节点的下一条边时，$color$ 要自增 $1$，这是为了防止当前节点的与当前节点另一个子节点的边染色相同。

最后根据输入边的顺序输出答案即可。
