#### [CF1141A](https://codeforces.com/contest/1141/problem/A)
**题意**：给你一个整数 $n$，每一次操作你可以将其乘以 $2$ 或乘以 $3$，求使其转化为 $m$ 的最小操作次数，如果无法变成 $m$ 输出 `-1`。

**数据范围**：$1 \leq n \leq m \leq 5 \times 10^8$。

**思路**：直接用 BFS 模拟，使用 map 记录到达当前数字的最小操作次数。

#### [CF1141B](https://codeforces.com/contest/1141/problem/B)
**题意**：给定一个长度为 $n$ 的 `01` 数组 $a$，数组循环交替（最后一个元素的下一个元素是第一个元素），求数组子段全为 $1$ 的最长子段长度。

**数据范围**：$1 \leq n \leq 2 \times 10^5$，$0 \leq a_i \leq 1$。

**思路**：将数组扩展为 $2n$，然后在新数组上做滑动窗口，求全为 $1$ 的子段的最大长度。
