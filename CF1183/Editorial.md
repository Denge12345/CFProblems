#### [CF1183B](https://codeforces.com/contest/1183/problem/B)
**题意**：有 $q$ 组样例，每个样例中给定一个长度为 $n$ 的数组和整数 $k$，找到最大的 $B$ 使得 $|a_i - B| \leq k$，如果没有，输出 $-1$。

**数据范围**：$1 \leq 1 \leq 100$，$1 \leq n \leq 100$，$1 \leq k \leq 10^8$，$1 \leq a_i \leq 10^8$。

**思路**：我们需要让数组中每个元素都满足 $|a_i - B| \leq k$，所以要先考虑数组中的最小值 $mi$，转化公式后得 $B - mi = k \Rightarrow B = k + mi$，最后再验证一下是否所有元素都满足 $|a_i - B| \leq k$，根据题意输出即可。

#### [CF1183C](https://codeforces.com/contest/1183/problem/C)
**题意**：有 $q$ 组样例，每个样例中给定四个整数 $k$，$n$，$a$，$b$，分别表示笔记本初始电量，游戏回合数。到达一个回合时，可以进行三种操作：

- 如果笔记本电量严格大于 $a$，可以直接玩，电池电量减少 $a$。
- 如果笔记本电量严格大于 $b$，可以边充电边玩，电池电量减少 $b$。
- 如果笔记本电量同时小于等于 $a$ 和 $b$，则输掉游戏。

如果在 $n$ 个回合后还有电量剩余，则说明完成了游戏。

求在可以完成游戏的情况下，进行直接玩操作的最大次数，如果怎样都无法完成游戏，输出 $-1$。

**数据范围**：$1 \leq q \leq 10^5$，$1 \leq k, n \leq 10^9$，$1 \leq b < a \leq 10^9$。

**思路**：对于每个数据，我们可以二分进行直接玩操作的最大次数。在一次二分中，如果可以完成游戏，则记录当前答案，缩小左边界；否则不记录答案缩小右边界。

对于如何判断是否完成游戏，定义进行直接玩操作的最大次数为 $x$，那么剩余的电量 $leftpower = k - x \times a$，剩余的回合数为$leftn = n - x$，为了使得可以完成后续回合，需要满足 $leftpower > leftn \times b$，如果 $leftpower \leq leftn \times b$ 则无法完成后续回合；否则可以完成后续回合。

也可以使用 $k - x \times a - y \times b > 0$，来判断是否可以完成后续回合，这里 $y = n - x$。

#### [CF1183D](https://codeforces.com/contest/1183/problem/D)
**题意**：有一个含有 $n$ 颗糖的糖果盒 $a$，第 $i$ 颗糖的种类为 $a_i$。你需要制作一份礼物，满足礼物中每种糖果的数量必须各不相同（比如，礼物里有两颗第 $1$ 种糖和两颗第 $2$ 种糖，那就不行，但是一颗第 $1$ 种糖和两颗第 $2$ 种糖就可以），输出最大礼物的大小（即糖果总数最多的礼物）。

**数据范围**：$1 \leq q \leq 2 \times 10^5$，$1 \leq n \leq 2 \times 10^5$，$1 \leq a_i \leq n$，保证所有查询中 $n$ 的总和不超过 $2 \times 10^5$。

**思路**：我们可以记录每种糖果的个数，然后将其存入数组 $arr$ 中，将数组升序排序后贪心地从大到小取糖果。

取的过程中记录一个变量 $nextTake$，表示下一次可以取小于等于 $nextTake$ 数量的糖果，每次都可以取 $min(arr_i, nextTake)$ 颗糖果，累加到答案 $ans$ 中。如果 $nextTake \leq arr_i$，则下一次可以取小于等于 $nextTake - 1$ 数量的糖果；否则下一次可以取 $arr_i - 1$ 数量的糖果，每一次取完后要更新 $nextTake$

#### [CF1183E](https://codeforces.com/contest/1183/problem/E)
**题意**：给定一个长度为 $n$ 的字符串 $s$，定义 $t$ 为 $s$ 其中的一个子序列，对于将 $s$ 变为 $t$ 的操作成本是 $n - |t|$，你需要将 $s$ 的子序列添加到集合 $S$（没有重复子序列），直到集合的大小为 $k$，求最少成本。

**数据范围**：$1 \leq n, k \leq 100$。

**思路**：暴力的方法就是使用 BFS，过程中维护一个集合 $st$，来到一个子序列 $cur$ 时创建一个它的副本 $ns$，然后枚举删除 $ns$ 中的字符，每次删掉一个得到一个新的子序列，如果集合中没有出现过操作后的子序列就将其添加到集合中，随后计算成本 $ ans += n - |ns|$，将其累加到答案中。当队列中为空或者集合 $st$ 的大小等于 $k$ 了就跳出循环，最后判断集合大小是否等于 $k$，如果满足则输出 $ans$，否则输出 $-1$。

#### [CF1183F](https://codeforces.com/contest/1183/problem/F)
**题意**： 有 $q$ 组样例，每组样例给定一个长度为 $n$ 的整数数组 $a$，你需要从数组中选择 $1 \sim 3$ 个数 $x$，$y$，$z$，满足一个数和其它的数字不能相互整除，问能选择出满足题意的数字中，累加和最大是多少。

**数据范围**：$1 \leq q \leq 2 \times 10^5$，$1 \leq n \leq 2 \times 10^5$，$2 \leq a_i \leq 2 \times 10^5$，保证每组样例中 $n$ 的总和不超过 $2 \times 10^5$。

**思路**：我们可以先处理一下数组，由于是选数字，所以和顺序没关系，我们可以将数组排序。因为要保证选出的数字两两不能整除，所以我们一定不会选择相同的数组，于是可以将数组去重。

接着我们可以从大往小选择数字，其中要保证选择的数字两两不能整除，选满了三个或者数组中没有数字可选了，那么就能得出答案了。

但是还有可能存在一种情况，当我们只选择了一个数字时，可能会存在选择比它小的三个数字，累加和比它更大，而且这三个数字两两不能整除。我们可以考虑 $2$，$3$，$5$ 这三个质数因子，选择出的一个数字一定是他们的公倍数，也就是 $30$ 的倍数。如果数组中的最大值 $mx$ 是 $30$ 的倍数，且存在一组数字是 $(\frac{mx}{2}, \frac{mx}{3}, \frac{mx}{5})$，那么这也算是一种答案，需要与之前使用贪心策略选出的数字进行比较。

由于我们需要选出的数字的累加和尽可能大，所以我们只考虑最大值是 $30$ 的倍数即可。

为什么只考虑 $2$，$3$，$5$ 这三个质数因子？我们可以写出式子，三个数的累加和为 $mx \times (\frac{1}{2} + \frac{1}{3} + \frac{1}{5})$，我们将括号内的式子同分后得到 $mx \times \frac{31}{30}$，这三个因子的组合一定可以增大 $mx$，因为 $\frac{31}{30} \geq 1$，其他质数因子的组合一定不能满足 $\frac{1}{a} + \frac{1}{b} + \frac{1}{c} \geq 1$，比如选择 $2$，$3$，$7$，得出的结果是 $\frac{41}{42}$。
