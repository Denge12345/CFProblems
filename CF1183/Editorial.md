#### [CF1183B](https://codeforces.com/contest/1183/problem/B)
题意：有 $q$ 组样例，每个样例中给定一个长度为 $n$ 的数组和整数 $k$，找到最大的 $B$ 使得 $|a_i - B| \leq k$，如果没有，输出 $-1$。

数据范围：$1 \leq 1 \leq 100$，$1 \leq n \leq 100$，$1 \leq k \leq 10^8$，$1 \leq a_i \leq 10^8$。

思路：我们需要让数组中每个元素都满足 $|a_i - B| \leq k$，所以要先考虑数组中的最小值 $mi$，转化公式后得 $B - mi = k \Rightarrow B = k + mi$，最后再验证一下是否所有元素都满足 $|a_i - B| \leq k$，根据题意输出即可。

#### [CF1183C](https://codeforces.com/contest/1183/problem/C)
题意：有 $q$ 组样例，每个样例中给定四个整数 $k$，$n$，$a$，$b$，分别表示笔记本初始电量，游戏回合数。到达一个回合时，可以进行三种操作：

- 如果笔记本电量严格大于 $a$，可以直接玩，电池电量减少 $a$。
- 如果笔记本电量严格大于 $b$，可以边充电边玩，电池电量减少 $b$。
- 如果笔记本电量同时小于等于 $a$ 和 $b$，则输掉游戏。

如果在 $n$ 个回合后还有电量剩余，则说明完成了游戏。

求在可以完成游戏的情况下，进行直接玩操作的最大次数，如果怎样都无法完成游戏，输出 $-1$。

数据范围：$1 \leq q \leq 10^5$，$1 \leq k, n \leq 10^9$，$1 \leq b < a \leq 10^9$。

思路：对于每个数据，我们可以二分进行直接玩操作的最大次数。在一次二分中，如果可以完成游戏，则记录当前答案，缩小左边界；否则不记录答案缩小右边界。

对于如何判断是否完成游戏，定义进行直接玩操作的最大次数为 $x$，那么剩余的电量 $leftpower = k - x \times a$，剩余的回合数为$leftn = n - x$，为了使得可以完成后续回合，需要满足 $leftpower > leftn \times b$，如果 $leftpower \leq leftn \times b$ 则无法完成后续回合；否则可以完成后续回合。

也可以使用 $k - x \times a - y \times b > 0$，来判断是否可以完成后续回合，这里 $y = n - x$。
