#### [CF141A](https://codeforces.com/contest/141/problem/A)
**题意**：给定三个字符串 $s1$，$s2$，$s$，判断是否恰好（没有多余字符）可以通过任何方式将 $s1$ 和 $s2$ 拼接成 $s$。

**数据范围**：每个字符串长度不超过 $100$。

**思路**：先判断 $s1$ 和 $s2$ 的长度相加是否等于 $s$ 的长度，如果相等继续做下一步判断，否则直接输出 `NO` 返回。记录 $s1$ 和 $s2$ 中每个字符的个数，然后遍历 $s$，遍历的过程中减少对应字符的数量，如果出现字符不足直接输出 `NO` 返回，否则遍历完成后输出 `YES`。

#### [CF141B](https://codeforces.com/contest/141/problem/B)
**题意**：有无穷个带有编号的边长为 $a$ 正方形，将这些正方形向 $y$ 轴正方向排布，排布规则类似跳房子游戏中的场地排布（$1-1-2-1-2-1-2\dots$）

![图片](https://espresso.codeforces.com/08e9ed9fbaf1166b177ff33493fff10adef9db20.png)

给定一个点的坐标 $(x, y)$，求这个点落在哪个编号的正方形中（必须是正方形内部），如果没有输出 `-1`。

**数据范围**：$1 \leq a \leq 100$，$-10^{6} \leq x \leq 10^6$，$0 \leq y \leq 10^6$。

**思路**：首先，如果 $y$ 能被 $a$ 整除（即 $y \bmod a = 0$），那么点恰好落在某一层正方形的上边界或下边界上，可以直接输出 `-1`。

否则，令 $k = \left\lfloor \dfrac{y}{a} \right\rfloor$ 表示该点所在的**层号**（从 $0$ 开始）。不同层上正方形的数量和分布如下表：

| 层号 $k$ | 方块数 | $x$ 的范围（内部）               | 编号     |
| -------- | ------ | -------------------------------- | -------- |
| $0$      | $1$    | $\vert x\vert < \dfrac{a}{2}$    | $1$      |
| $1$      | $1$    | $\vert x\vert < \dfrac{a}{2}$    | $2$      |
| $2$      | $2$    | $-a < x < 0$                     | $3$      |
|          |        | $0 < x < a$                      | $4$      |
| $3$      | $1$    | $\vert x\vert < \dfrac{a}{2}$    | $5$      |
| $4$      | $2$    | $-a < x < 0$                     | $6$      |
|          |        | $0 < x < a$                      | $7$      |
| $5$      | $1$    | $\vert x\vert < \dfrac{a}{2}$    | $8$      |
| $\dots$  | $\dots$| $\dots$                          | $\dots$  |

可以观察到规律：
- 若 $k = 0$ 或 $k$ 为奇数，这一层只有 $1$ 个正方形，位于中间；
- 若 $k$ 为正偶数，这一层有 $2$ 个正方形，分列左右，中间有缝隙。

无论哪种情况，我们都需要知道在第 $k$ 层之前一共有多少个正方形，记作 $T(k)$。那么第 $k$ 层正方形的编号就是 $T(k) + 1$ 开始的连续整数。

当 $k = 0$ 或 $k$ 为奇数时，前面有第 $0$ 层的 $1$ 个正方形，以及 $\dfrac{k-1}{2}$ 组“一个单方块层 + 一个双方块层”（每组共 $3$ 个正方形）。  
因此：
$$
T(k) = 1 + 3 \times \frac{k-1}{2}
$$
编号为：
$$
\text{编号} = T(k) + 1 = 2 + \frac{3(k-1)}{2} = \frac{3k+1}{2}
$$

当 $k = 0$ 时，直接代入上式会得到 $-1$，但实际编号应为 $1$。所以代码中使用 `max(1, (3*k+1)/2)` 来统一处理。

这一层正方形的左右边界是 $x = \pm \dfrac{a}{2}$。因此，如果 $2 \times |x| \ge a$，点就在左右边界或外部，输出 `-1`；否则输出计算出的编号。

当 $k$ 为偶数时，前面有：第 $0$ 层的 $1$ 个正方形，$\left(\dfrac{k}{2} - 1\right)$ 组“单+双”（每组 $3$ 个），以及第 $k-1$ 层（奇数层）的 $1$ 个正方形。  
因此：
$$
T(k) = 1 + 3\left(\frac{k}{2} - 1\right) + 1 = \frac{3k}{2} - 1
$$
左方块的编号为 $T(k) + 1 = \dfrac{3k}{2}$，  
右方块的编号为 $T(k) + 2 = \dfrac{3k}{2} + 1$。

那么，如何判断点落在左边还是右边呢？  
左方块区域：$-a < x < 0$，右方块区域：$0 < x < a$。  
将不等式整体 $+a$，得到：
- 左：$0 < x + a < a$
- 右：$a < x + a < 2a$

利用整数除法，$\left\lfloor \dfrac{x+a}{a} \right\rfloor$ 在左区间得 $0$，在右区间得 $1$。于是编号可以直接写成：
$$
\text{编号} = \frac{3k}{2} + \left\lfloor \frac{x+a}{a} \right\rfloor
$$

这一层的内部要求是 $-a < x < 0$ 或 $0 < x < a$，等价于 $0 < |x| < a$。因此，如果 $x = 0$ 或 $|x| \ge a$，点落在边界或外部，输出 `-1`；否则用上式算出编号。
