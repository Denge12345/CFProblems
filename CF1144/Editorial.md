#### [CF1141A](https://codeforces.com/contest/1144/problem/A)
**题意**：如果一个长度为 $n$ 的字符串 $s$，如果其中每一个字母在字母表中是连续的（比如 `fced`，因为 `cdef` 是连续的），且每个字母恰好出现一次，输出 `Yes` 否则输出 `No`。

**数据范围**：$1 \leq n \leq 100$。

**思路**：将字母存入数组，然后进行排序，对于每一个 $i \in [1, n - 1]$ 如果 $a_{i - 1} + 1 \neq a_i$ 则输出 `No` 否则输出 `Yes`。

#### [CF1144B](https://codeforces.com/contest/1144/problem/B)
**题意**： 给定一个长度为 $n$ 的数组 $a$，你可以选择任何一个元素进行删除，但是删除的顺序必须是奇偶交替的（奇-偶-奇-偶或偶-奇-偶-奇），你需要最小化未删除元素的和，请问和是多少。

**数据范围**：$1 \leq n \leq 2000$，$0 \leq a_i \leq 10^6$。

**思路**：由于可以选择任何一个元素，而且删除的顺序必须是奇偶交替的，我们不妨将奇偶数分开存放。由于我们需要最小化未删除元素的和，贪心地想，我们肯定先考虑最大的元素，所以可以将数组从小到大进行排序。

我们定义奇数数组大小为 $o$，偶数数组大小为 $e$，则当 $|e - o| \leq 1$ 时，我们肯定能通过交替删除使得未删除元素的和为 $0$，即删除全部元素。

当 $e > o$ 时，我们可以删除奇数数组中的全部元素，最后剩余偶数数组的元素个数为 $e - o$；当 $e > o$ 时，我们可以删除偶数数组中的全部元素，最后剩余奇数数组的元素个数为 $o - e$。最后我们累加剩余数组中的元素即可。

#### [CF1144C](https://codeforces.com/contest/1144/problem/C)
**题意**：给定一个长度为 $n$ 的序列 $a$，找到一个严格递增和一个严格递减的序列，输出元素个数和序列中的元素，如果不存在输出 `NO`。

**数据范围**：$1 \leq n \leq 2 \times 10^5$，$0 \leq a_i \leq 2 \times 10^5$。

**思路**：由于我们找的是序列，不关心数组内元素的相对顺序，我们可以先进行计数。由于我们要输出的序列是严格递增和递减的，那么如果存在一个元素其个数超过两个，直接输出 `NO`，否则为 `YES`。

然后我们可以先构造一次递增的序列，也就是升序在计数数组中选数，别忘了减少元素的个个数。接着可以再构造一次递增序列，然后将其反转。

最后根据题目要求输出即可。
