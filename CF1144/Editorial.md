#### [CF1144B](https://codeforces.com/contest/1144/problem/B)
**题意**： 给定一个长度为 $n$ 的数组 $a$，你可以选择任何一个元素进行删除，但是删除的顺序必须是奇偶交替的（奇-偶-奇-偶或偶-奇-偶-奇），你需要最小化未删除元素的和，请问和是多少。

**数据范围**：$1 \leq n \leq 2000$，$0 \leq a_i \leq 10^6$。

**思路**：由于可以选择任何一个元素，而且删除的顺序必须是奇偶交替的，我们不妨将奇偶数分开存放。由于我们需要最小化未删除元素的和，贪心地想，我们肯定先考虑最大的元素，所以可以将数组从小到大进行排序。

我们定义奇数数组大小为 $o$，偶数数组大小为 $e$，则当 $|e - o| \leq 1$ 时，我们肯定能通过交替删除使得未删除元素的和为 $0$，即删除全部元素。

当 $e > o$ 时，我们可以删除奇数数组中的全部元素，最后剩余偶数数组的元素个数为 $e - o$；当 $e > o$ 时，我们可以删除偶数数组中的全部元素，最后剩余奇数数组的元素个数为 $o - e$。最后我们累加剩余数组中的元素即可。

#### [CF1144D](https://codeforces.com/contest/1144/problem/D)
**题意**：给定一个长度为 $n$ 的数组 $a$，你可以进行任意次如下操作：

1. 选择一对相邻的索引 $(i, j)$，然后将 $a_i$ 改为 $a_i + |a_i - a_j|$。
2. 选择一对相邻的索引 $(i, j)$，然后将 $a_i$ 改为 $a_i - |a_i - a_j|$。

找到最小操作次数，并输出执行操作的顺序，第 $p$ 次操作为三个整数 $(t_p, i_p, j_p)$，其中 $t_p$ 为 $1$ 或 $2$。

**数据范围**：$1 \leq n \leq 2 \times 10^5$，$0 \leq a_i \leq 2 \times 10^5$。

**思路**：先理解一下题目的操作，假设有两个数字 $2$ 和 $4$，那么我们可以修改 $2$，也可以修改 $4$，因为题目中并没有规定 $i < j$。所以可以将 $2$ 改为 $4$，操作为 $(1, 1, 2)$，也可以将 $4$ 改为 $2$，操作为 $(2, 2, 1)$

由于我们要求最小操作次数，贪心地想，一定是将其他数字改为出现次数最多的数字，我们可以找到这个元素的位置 $maxCntPos = i$ 和这个元素 $target = a_i$，然后向左右两边去扩充，当遇到相同的数字时，直接跳过。

为什么可以向左右两边扩充？因为当给下一个元素进行修改时，相邻两边的元素有一个必定是修改好的，即 $a_{i+1}$ 或 $a_{i-1}$ 为 $target$。

当向左扩充时，如果 $a_i > target$，则执行操作 $2$，操作为 $(2, i, i + 1)$，否则执行操作 $1$，操作为 $(1, i, i + 1)$。

当向右扩充时，如果 $a_i > target$，则执行操作 $2$，操作为 $(2, i, i - 1)$，否则执行操作 $1$，操作为 $(1, i, i - 1)$。

最后按照题意输出即可。
